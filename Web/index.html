TWM / CHARACTER CUSTOMIZATION

Skin Replacer

Управление скинами игровых организаций

Установка пользовательских скинов

Выбери организацию и пол, затем укажи одну пару файлов .dff (модель) и .txd (текстура). Лаунчер установит её для всех ID выбранной группы в models\assets\skins.

ⓘПеред заменой создаётся резервная копия исходных файлов. Если какого-либо исходного файла не было, это также учитывается при восстановлении.

1. Организация и группа

Будут заменены 8 моделей: hmyri, bmymoun, maffa, maffb, vla2, vla3, sfr2, forelli

2. Файлы пользовательского скина

Выбери соответствующие друг другу модель и текстуру. Исходные файлы не перемещаются и не переименовываются.

DFF
МодельФайл не выбран

Выбери оба файла для установки.

Автоматическая проверка обновлений при запуске

TWM / CONFIGURATION

Настройки лаунчера

Папка игры

Выбери папку, в которой находится aggstarter.exe.

Игровой никнейм

Используется при запуске клиента.

Целевой процесс

Выбери процесс, по которому лаунчер определяет активный игровой клиент. Запуск по-прежнему выполняется через aggstarter.exe.

Диагностика запуска

Проверь основные файлы перед запуском игры. Проверка ничего не изменяет в папке игры.

Нажми «Проверить», чтобы проверить файлы клиента и QuickASI.

ASI-загрузчик

Включай QuickASI только для сборок, которым нужен ASI-загрузчик.

Библиотека DLL / ASI

Управляй модификациями в одном общем списке. Для включения и отключения модов игра должна быть закрыта.

Нажми «Обновить», чтобы загрузить список модов.

Растительность

Переключает состояние через файл .ignored в папках models\assets\vegetation\foliage и no_foliage.

Состояние будет определено по расположению .ignored.

Подсказка F1

Изображение из amazing\f1_help_overlay.png. Допускаются только PNG-файлы.

Изображение F1 не найдено
Выбери PNG, чтобы заменить подсказку.

Данные лаунчера

Настройки и служебные данные хранятся отдельно от файлов игры.

Изменения применяются после сохранения.
